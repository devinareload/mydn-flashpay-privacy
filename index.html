Kebijakan Privasi Aplikasi

Terakhir diperbarui: 01 Oktober 2026

Kebijakan Privasi ini menjelaskan bagaimana myDN FlashPay ("kami", "aplikasi") mengumpulkan, menggunakan, dan melindungi informasi Anda saat menggunakan aplikasi kami. Dengan mengunduh dan menggunakan aplikasi ini, Anda menyetujui kebijakan yang tertuang di halaman ini.

1. Informasi yang Kami Kumpulkan

Aplikasi myDN FlashPay mengumpulkan dan memproses informasi berikut:

  • Notifikasi Perangkat (Lokal): Aplikasi membaca notifikasi uang masuk dari aplikasi perbankan atau e-wallet yang Anda pilih untuk mendeteksi transaksi secara otomatis. Pemrosesan teks notifikasi dilakukan sepenuhnya di dalam perangkat Anda.
  • Aktivitas Web Browser & Riwayat (Lokal): Aplikasi menyediakan fitur Web Browser internal untuk memudahkan pengguna membuka mesin pencari, website server pulsa/mitra masing-masing, maupun situs lainnya. Riwayat penjelajahan (browsing history) dan bookmark disimpan secara lokal di perangkat dan tidak dikirim ke server pihak luar manapun.
  • Sandi & Kredensial Pengguna: Fitur penyimpanan akun, sandi, dan autofill didukung langsung oleh sistem Android (Android Autofill Framework) dan penyimpanan lokal peramban demi kenyamanan login Anda. Kami tidak menyimpan atau mentransmisikan sandi Anda ke server kami.
  • Data Transaksi: Nominal dan status validasi disimpan di database lokal perangkat serta disinkronkan ke Firebase Realtime Database untuk tampilan riwayat transaksi Anda.
  • Preferensi Pengguna: Pengaturan aplikasi (tema tampilan, status layanan, lisensi/kunci pengguna) disimpan di penyimpanan lokal perangkat.

2. Cara Kami Menggunakan Informasi

Informasi yang dikumpulkan digunakan untuk tujuan berikut:

  • Mendeteksi mutasi saldo masuk dan memvalidasi deposit di website mitra/server pilihan pengguna secara otomatis
  • Menyediakan fungsionalitas penjelajahan web, pengelolaan bookmark, dan riwayat penjelajahan yang praktis bagi pengguna
  • Menampilkan riwayat transaksi dan status keberhasilan validasi
  • Menjalankan layanan latar belakang agar otomasi tetap aktif ketika layar mati atau beralih aplikasi

3. Penyimpanan dan Keamanan Data

Data riwayat transaksi disinkronkan menggunakan Google Firebase Realtime Database dengan enkripsi SSL/TLS standar industri. Data notifikasi perbankan, riwayat browsing web, bookmark, dan kredensial login disimpan secara lokal di memori internal perangkat Anda.

Kami tidak menjual, memperjualbelikan, atau menyewakan data pribadi Anda kepada pihak lain tanpa persetujuan Anda, kecuali jika diwajibkan oleh ketentuan hukum yang berlaku.

4. Izin Perangkat yang Digunakan

  • Akses Notifikasi (Notification Listener): Untuk membaca notifikasi mutasi saldo masuk dari aplikasi bank/e-wallet secara otomatis
  • Akses Internet: Untuk memuat website pada peramban internal, sinkronisasi data Firebase, serta pemuatan iklan
  • Layanan Latar Depan (Foreground Service): Untuk menjaga layanan pemantau mutasi tetap berjalan di latar belakang tanpa terhenti oleh sistem penghemat baterai
  • Mulai Saat Perangkat Menyala (Boot Completed): Untuk menjalankan kembali layanan otomatisasi setelah perangkat dinyalakan ulang

5. Iklan dalam Aplikasi (Google AdMob)

Aplikasi myDN FlashPay menampilkan iklan yang disediakan oleh Google AdMob guna menunjang penyediaan, pengembangan, dan keberlanjutan layanan aplikasi ini secara gratis kepada pengguna.

Terkait iklan, berikut informasi penting yang perlu Anda ketahui:

  • Bentuk Iklan: Banner iklan ditampilkan di bagian bawah layar aplikasi tanpa mengganggu penggunaan fitur utama.
  • Data yang Dikumpulkan oleh AdMob: Google AdMob dapat mengumpulkan informasi pengidentifikasi perangkat (seperti Google Advertising ID), alamat IP, serta interaksi iklan untuk keperluan penargetan dan analisis efektivitas iklan.
  • Kontrol Personalisasi Iklan: Anda memiliki kendali penuh untuk menonaktifkan personalisasi iklan melalui menu pengaturan perangkat Android Anda di: Setelan → Google → Iklan → Hapus ID Iklan / Pilih Keluar dari Personalisasi Iklan.

Pelajari lebih lanjut tentang bagaimana Google memproses data melalui tautan resmi: Kebijakan Google Partner Sites.

6. Layanan Pihak Ketiga

Aplikasi ini dapat berinteraksi dengan layanan pihak ketiga berikut:

  • Google Firebase — untuk sinkronisasi cloud data riwayat mutasi
  • Google AdMob — untuk penayangan iklan guna menunjang operasional aplikasi
  • Website Server / Platform Pilihan Pengguna — platform pihak ketiga yang dibuka secara mandiri oleh pengguna melalui fitur Web Browser

7. Perlindungan Privasi Anak-Anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia 13 tahun. Kami tidak mengumpulkan data pribadi anak-anak. Jika Anda meyakini terdapat data anak yang tidak sengaja tercatat, hubungi kami agar dapat segera dihapus.

8. Pembaruan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui sewaktu-waktu seiring dengan penambahan fitur atau penyesuaian regulasi. Setiap pembaruan akan dipublikasikan pada halaman ini. Anda dianjurkan untuk meninjau halaman ini secara berkala.

9. Hubungi Kami

Apabila Anda memiliki pertanyaan, saran, atau masukan terkait Kebijakan Privasi ini, silakan hubungi kontak pengembang yang tertera pada listing aplikasi di Google Play Store.
